# データ辞書 / 欄位對照表（IMT スプレッドシート）

> 目的：引継ぎ・将来メンテのため、**シート列名（コードが参照する実キー）** と **UI 上の呼称（現行の概念）** の対応を明示する。
> 重要：**コードは列名（ヘッダー文字列）で値を読む**。ヘッダーを改名するとコードの参照が壊れる（改名する場合は index.html / setup-sheet.gs の該当キーも同時に直すこと）。
> 凡例：✅=現役 / ⚠️=旧設計の名残（将来撤去予定）
