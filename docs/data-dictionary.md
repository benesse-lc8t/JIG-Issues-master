## 削除手順（🗑️ 列・2026-06-02 旧タブ撤去後）
旧タブ撤去（index.html v0.48.0）でコード依存が消えたため、以下は **スプレッドシート側で削除してよい**：
- **Issue主檔**：`區分 / 軸 / Issue短縮 / 處 / 組 / 管理頁面 / 確認會議 / 會議時間`
- **Mission一覽**：`管理頁面`
- **シート**：`組別頁面`、担当者の一覧シート（いずれも 0 参照）
> 注意：`事務局備註`（Issue主檔）は **残す**（My Work が Issue 進度メモに使用）。
> 削除後は念のためダッシュボードを再読込し、My Work が正常表示されるか確認すること（`編號/Issue` さえ在れば読込は止まらない）。

## ヘッダー改名について
- ヘッダー改名（擔當→DRI 等）をするなら、index.html / setup-sheet.gs の同名キー参照を**同時に**置換すること。単独改名はコードの参照を壊す。本辞書はそのための対照表。
