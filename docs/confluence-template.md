# Confluence ページ雛形（1組1ページ）

> 対象：事務局が各組向けに用意する Confluence ページの**雛形**。
> 設計根拠：CLAUDE.md §6「Confluence ページ設計」。
> 方針：A型（State型）= 現況は最新で上書き、履歴ログは折りたたみ＋節目のみ追記。

---

## 使い方（事務局向け）

1. Confluence の管理スペース（例：JIG）に、組ごとに1ページずつ作成する。
2. ページタイトル：`[組名] Issue管理ページ`（例：`經營戰略組 Issue管理ページ`）
3. 下記の Markdown 構造を**コピペ**してページ本体に貼る。Confluence Cloud の場合：
   - `/markdown` スラッシュコマンドで Markdown 入力モードに切替 → 貼り付け
   - または、新規ページで「インポート → Markdown」を使う
4. 各組の Issue 編號・名称に書き換えて初期化する。
5. 担当者（戰略負責人）にページURLを共有する。スプレッドシート `組ページ` シートにも登録する（sheet-setup.md §3 参照）。

---

## 記入者（戰略負責人）向け：1ページの使い方

### 週1回やること（5〜10分）

1. **トップ「今週の動き」** を上書き（3〜5行）
2. **動いたIssueの「現況」** を1行で上書き（古い記述は消えてOK。版履歴に自動保存される）
3. **節目があれば履歴ログに1行追記**（毎週は不要）
4. **Task のチェックボックス**を更新

### 書き換えのルール

- 「現況」は **最新の状態だけ** を1〜2行で書く。「○月○日 現在こういう状態」と書く。
- 履歴ログは **フェーズ転換** や **重大判断** や **停滞解除** など、節目だけ追記。
- 何を書くか迷ったら、トップの「今週の動き」だけ更新する。

## なぜこの構造か（設計メモ）

- **「今週の動き」がトップ**：会議参加者の最大の関心事を秒で渡す。
- **「現況」は上書き型**：最新がどれか迷わない。古い日付のままだと「動いてない」が露呈する（鮮度が可視化される）。
- **履歴ログは折りたたみ**：普段は隠れて邪魔にならない。深掘りしたい時だけ開く。
- **Task は Confluence ネイティブのチェックボックス**：チェック状態が Confluence 全体で集計可能。

詳細は CLAUDE.md §6 を参照。
