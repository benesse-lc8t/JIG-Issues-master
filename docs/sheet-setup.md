# Google スプレッドシート 列追加手順書（v0.5.0 対応）

> 対象：事務局（管理者・経営戦略組）
> 目的：本ツールが必要とする列を、現行スプレッドシートに追加する。
> 前提：CLAUDE.md の §5「データモデル」と整合する。

---

## ⚡ 最短手順：Apps Script で一発セットアップ（推奨）

スプレッドシートに `scripts/setup-sheet.gs` を貼り付けて 1 回実行するだけで、
下記 §1〜§3 の手順がすべて自動で済む。手動でやる必要はほぼ無い。

1. 対象スプレッドシートを開く
2. 拡張機能 → Apps Script
3. リポジトリの **`scripts/setup-sheet.gs`** の中身を全てコピー＆貼り付け（既存コードは置き換え）
4. 保存（💾）→ 上部の関数欄で `setupJIG` を選び ▶ 実行
5. 初回のみ権限承認を求められる → 自分のアカウントで承認
6. 完了。スプレッドシートに戻ると上部に「**JIG**」メニューが出る（次回はメニューから 1 クリック）

スクリプトが自動でやること：
- `Issue主檔` に不足列（`Confluence URL` / `狀態` / `事務局備註` / `更新日`）を追加
- `Task一覽` タブの新規作成＋ヘッダ整備
- `狀態` 列のプルダウン（未開始/進行中/完成）
- `狀態` の3色条件付き書式
- `更新日` の鮮度色変化（7日黄／14日赤）
- 列幅・ヘッダ行 freeze

再実行は安全（既にある列・タブは触らない／条件付き書式は重複しないよう検出して追加）。

> 以下は手動でやりたい人向けの参考。Apps Script で済ませた場合は不要。

## 構成の全体像（v0.5.0）

スプレッドシートは **2 タブ運用**：

| タブ名 | 役割 | 行数の目安 |
|---|---|---|
| `Issue主檔`（既存） | Issue マスタ | 〜50行 |
| `Task一覽`（新規） | 全 Task を 1 枚に集約 | 必要に応じて伸縮 |

ダッシュボードは両方を読み込み、Task を親 Issue にネスト表示する（▶ で展開）。

---

## 1. `Issue主檔` シートに追加する列

現行列の右側に、以下の順で **4 列** を追加する（種別・親編號は廃止）。

| # | 列名 | 値の例 | 記入者 | 備考 |
|---|---|---|---|---|
| L | `Confluence URL` | `https://…/組ページ#共-1` | 事務局（数式可） | 下記 §3 で自動化 |
| M | `狀態` | `未開始` / `進行中` / `完成` | **事務局（会議時に更新）** | 3段階。プルダウン推奨 |
| N | `事務局備註` | `営業組確認待ち（5/15から停滞）` | **事務局（随時更新）** | 観察メモ。自由テキスト |
| O | `更新日` | `2026-05-29` | 事務局（更新時に手動） | 古いと色変化（条件付き書式） |

> 列の位置（L〜O）は現行が A〜K の11列である前提。読み替えること。
> なお `區分` `軸` 列は**シートには残してOK**（ダッシュボードでは v0.5.0 から非表示）。

---

## 2. `Task一覽` シートを新規作成

タブ追加 → 名前を `Task一覽` にして、1 行目に以下のヘッダを並べる。

| 列 | 列名 | 例 | 必須 | 説明 |
|---|---|---|---|---|
| A | `編號` | `戰略-1-T1` | ✓ | Task ID。親編號 + `-T番号` を推奨 |
| B | `Task` | `KOL誘導フロー設計` | ✓ | Task 内容（または `Issue` という列名でも可） |
| C | `親編號` | `戰略-1` | ✓ | 紐づく Issue の編號（`Issue主檔` の C 列と一致） |
| D | `戰略負責人` | `育菱` | ─ | Task 固有の担当（空欄なら親 Issue の担当を継承） |
| E | `狀態` | `進行中` | ─ | プルダウンで `未開始/進行中/完成` |
| F | `事務局備註` | `5/22 設計レビュー通過` | ─ | 自由テキスト |
| G | `更新日` | `2026-05-29` | ─ | 古いと色変化（条件付き書式） |
| H | `Confluence URL` | （任意） | ─ | 空欄なら親 Issue のURLを継承 |

**継承される列**（Task 一覧シートに書く必要なし）：
`處 / 組 / 管理頁面 / 確認會議 / 會議時間` は親 Issue から自動補完される。

## 3. Google Sheet 上の設定（共通）

### プルダウン（狀態）
- 対象列を選択 → データ → データの入力規則
- 条件：「リストを直接指定」→ `未開始,進行中,完成`
- 無効なデータの場合：入力を拒否

### 条件付き書式（狀態の色）
- `未開始` → 背景：薄グレー
- `進行中` → 背景：薄青
- `完成`   → 背景：薄緑

### 更新日の鮮度色（同様に両シートに適用）
- ルール1（7日超）：`=AND($G2<>"", TODAY()-$G2>7, TODAY()-$G2<=14)` → 薄黄
- ルール2（14日超）：`=AND($G2<>"", TODAY()-$G2>14)` → 薄赤
- ※ G2 は `Task一覽` の更新日列の位置。`Issue主檔` 側は読み替え

### Confluence URL の自動生成（任意）
別シート `組ページ` を作って組ごとのベースURLを管理し、`Confluence URL` を数式で組み立てると保守が楽：
```
=IFERROR(VLOOKUP(G2, 組ページ!A:B, 2, FALSE) & "#" & C2, "")
```
（G2=組、C2=編號）

## 4. Task を追加するときの運用

1. `Task一覽` シートを開く
2. 行末に新しい行を追加
3. `編號` `Task` `親編號` を最低限入力（残りは必要に応じて）
4. ダッシュボードを再読込 → 該当 Issue 行の ▶ から展開して表示される

---

## 5. 役割分担（再掲）

| 担当 | やること | 入力先 | 頻度 |
|---|---|---|---|
| **本人** | Confluence の組ページで「現況」を上書き、節目で履歴ログ追記 | Confluence | 週1 |
| **事務局** | `Issue主檔` の `狀態` を更新 | スプレッドシート | 確認会議の都度 |
| **事務局** | `Issue主檔` の `事務局備註` を更新（観察メモ） | スプレッドシート | 随時 |
| **事務局** | `Task一覽` で Task の追加・更新・チェック | スプレッドシート | 会議中／終了時 |

**本人の本ツールへの入力は引き続きゼロ。** Task のメンテも事務局が行う。
