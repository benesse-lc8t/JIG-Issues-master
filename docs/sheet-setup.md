# Google スプレッドシート 列追加手順書

> 対象：事務局（管理者・経営戦略組）
> 目的：本ツールが必要とする列を、現行スプレッドシートに追加する。
> 前提：CLAUDE.md の §5「データモデル」と整合する。

---

## 1. 追加する列（最終形）

現行列の右側に、以下の順で **6列** を追加する。

| # | 列名 | 値の例 | 記入者 | 備考 |
|---|---|---|---|---|
| L | `種別` | `Issue` または `Task` | 事務局（追加時） | 既存行は全て `Issue`。Task行を増やすときに使う |
| M | `親編號` | `共-1`（Task行のみ） | 事務局（追加時） | Issue行は空欄 |
| N | `Confluence URL` | `https://…/組ページ#共-1` | 事務局（数式） | 下記 §3 で自動化 |
| O | `狀態` | `未開始` / `進行中` / `完成` | **事務局（会議時に更新）** | 3段階。プルダウン推奨 |
| P | `事務局備註` | `営業組確認待ち（5/15から停滞）` | **事務局（随時更新）** | 観察メモ。自由テキスト |
| Q | `更新日` | `2026-05-29` | 事務局（更新時に手動） | 古いと色変化（条件付き書式） |

> 列の位置（L〜Q）は現行が A〜K の11列である前提。実際のシートで列文字を確認して読み替え。

---

## 2. 具体的な手順（Google Sheet 上で）

### 手順1：列を追加する

1. シート `Issue主檔` を開く
2. L列ヘッダで右クリック → 「列を1つ右に挿入」を **6回** 実行
3. 1行目（ヘッダ）に以下を入力：

   | L1 | M1 | N1 | O1 | P1 | Q1 |
   |---|---|---|---|---|---|
   | `種別` | `親編號` | `Confluence URL` | `狀態` | `事務局備註` | `更新日` |

### 手順2：既存行の `種別` を埋める

L列（種別）の **2行目以降すべて** に `Issue` を入れる。
- 一括方法：L2 に `Issue` を入力 → L2セルを選択 → 右下のフィルハンドルを最終行までドラッグ

### 手順3：狀態にプルダウンを設定する

1. O列の2行目以降を選択
2. メニュー：データ → データの入力規則
3. 条件：「リストを直接指定」→ `未開始,進行中,完成`
4. 「無効なデータの場合：入力を拒否」にチェック
5. 保存

### 手順4：色付き条件付き書式（狀態）

1. O列を選択
2. 表示形式 → 条件付き書式
3. 以下3ルールを追加：
   - テキストが完全に一致 `未開始` → 背景：薄グレー
   - テキストが完全に一致 `進行中` → 背景：薄青
   - テキストが完全に一致 `完成` → 背景：薄緑

### 手順5：更新日の色変化（鮮度の可視化）

1. Q列を選択
2. 条件付き書式 → 「カスタム数式」
3. ルール1（7日超で黄）：
   ```
   =AND($Q2<>"", TODAY()-$Q2>7, TODAY()-$Q2<=14)
   ```
   背景：薄黄
4. ルール2（14日超で赤）：
   ```
   =AND($Q2<>"", TODAY()-$Q2>14)
   ```
   背景：薄赤

## 3. Confluence URL の自動生成（数式化）

各組ページのベースURLを別シートで管理し、N列を数式で組み立てる。

### 手順A：別シート `組ページ` を作る

| A（組） | B（ベースURL） |
|---|---|
| 經營戰略 | `https://….atlassian.net/wiki/spaces/JIG/pages/12345/經營戰略組Issue管理` |
| 通路整合 | `https://….atlassian.net/wiki/spaces/JIG/pages/12346/通路整合組Issue管理` |
| … | … |

### 手順B：N列に数式

`Issue主檔` シートの N2 に：
```
=IFERROR(VLOOKUP(G2, 組ページ!A:B, 2, FALSE) & "#" & C2, "")
```
> G2 = 組、C2 = 編號。組が `組ページ` シートに登録されていれば、自動でアンカー付きURLが生成される。

N2 をN列最終行までフィル。

## 4. Task行を追加するとき（運用）

Issue配下に具体タスクを追加したい場合：

1. 該当Issueの**直下**に新しい行を挿入
2. 各列に：
   - A `區分` ～ G `組`：Issueと同じ値（コピー）
   - H `戰略負責人`：そのTaskの担当（Issueと違ってもよい）
   - I `管理頁面` ～ K `會議時間`：Issueと同じ
   - C `編號`：`共-1-T1` のような命名（親編號 + `-T` + 連番）
   - D `Issue` / E `Issue短縮`：Task名
   - **L `種別`：`Task`**
   - **M `親編號`：`共-1`**（親Issueの編號）
   - N `Confluence URL`：数式が自動で埋める（組ページ内の同じアンカー）
   - O 狀態・P 事務局備註：必要に応じて

> 編號命名の T 番号は重複しないように事務局で管理。

---

## 5. 運用時の留意点

- **本人にこのシートを触らせない**。入力は全て事務局で行う。
- 狀態は確認会議の場で事務局が更新する（議事録代わり）。
- 事務局備註は会議外でも随時更新する（観察メモなので）。
- 更新日は、狀態または事務局備註を更新した日を入れる。**自動化したい場合は Apps Script で onEdit トリガーを書く**（将来案）。
